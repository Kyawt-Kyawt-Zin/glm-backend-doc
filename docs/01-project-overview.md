# Project Overview

## Project Title

Golden Loom Myanmar: A Full-Stack E-Commerce Web Application for Myanmar-Made Sweaters in Dubai

## Project Summary

Golden Loom Myanmar is a full-stack e-commerce web application developed as my final web development project. The application is designed to sell sweaters made in Myanmar to customers in Dubai.

Customers will be able to browse sweater products, choose available colors and sizes, add products to a cart, and place orders. The system will support both in-stock products and preorder products. In-stock orders will use cash on delivery, while preorder orders require a 20% deposit that staff must confirm.

## Problem Statement

Managing sweater sales through messages or social media can make it difficult to track product availability, customer orders, payments, delivery options, and preorder details. This project provides one organized system for customers, staff, and administrators.

## Project Objectives

- Create an online store for Myanmar-made sweaters.
- Manage product colors, sizes, stock, and preorder options.
- Support cash on delivery for in-stock orders.
- Support a 20% deposit for preorder orders.
- Allow staff to confirm deposits and update order status.
- Allow customers to track their own orders.
- Provide admin access to manage products, staff, customers, and orders.

## Target Users

- Customers who want to purchase sweaters in Dubai.
- Staff who manage orders, stock, payments, and delivery updates.
- Administrators who manage the whole system.

## Technology Stack

- Frontend: React with JavaScript, Tailwind, React JS, CSS
- Backend: Node.js and Express with JavaScript
- Database: MySQL
- API Style: REST API

## Project Scope

The first version will include product management, product variants, cart, orders, preorder deposits, cash on delivery for in-stock orders, standard delivery, express delivery, pickup time slots, email order updates, and three user roles: customer, staff, and admin.

## Future Improvements

Future versions may include a real online payment gateway, courier API integration, discount codes, product reviews, and multiple languages.
